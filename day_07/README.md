## NumPy

### NumPy Arrays

- NumPy is a Python library mainly used for numerical and mathematical operations.
- It provides an efficient array structure for working with numerical data.
- Operations can be performed on the entire array at once.
- Arrays can be indexed and modified similar to Python lists.
- NumPy also supports multidimensional arrays.

### NumPy Operations

- Addition, multiplication and division can be performed directly on arrays.
- Two NumPy arrays can be used together for arithmetic operations.
- `np.zeros()` creates an array containing zeros.
- `np.ones()` creates an array containing ones.
- `np.arange()` creates a sequence of numbers.
- `np.sum()` calculates the sum of the elements.
- `np.mean()` calculates the average.
- `np.max()` finds the maximum value.
- The `shape` property gives the dimensions of an array.

## HTTP Requests

### urllib

- `urllib` is a built-in Python module used to access websites.
- It can send a request to a URL and receive a response.
- The response status can be checked using the status code.
- A status code of `200` indicates a successful request.

### Requests Library

- `requests` is an external Python library that provides simpler syntax for HTTP requests.
- A GET request is used to retrieve information from a server.
- `status_code` provides the HTTP response status.
- `text` provides the content returned by the server.
- POST requests can be used to send data to a server.
